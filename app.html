Catatan yang dihapus

Stok barang

Stok awal dan pembelian menambah persediaan. Nilainya menjadi biaya saat barang terjual atau dipakai. Jangan masukkan biaya yang sama lagi sebagai biaya operasional.
Bagaimana stok dihitung?

Harga modal memakai rata-rata tertimbang: nilai stok yang tersedia dibagi jumlahnya. Setiap penjualan mengurangi stok dan masuk ke harga pokok penjualan (HPP). Pembelian stok tidak langsung mengurangi laba. Pengurangan stok karena terpakai atau rusak masuk ke biaya.

Untuk makanan, kamu bisa mencatat menu siap jual. Jika yang dicatat adalah bahan, kurangi bahan saat dipakai dan jangan hitung lagi sebagai HPP manual pada penjualan. Resep, konversi satuan, dan produksi otomatis belum tersedia. Stok memakai jumlah bulat; pilih satuan kecil seperti gram atau ml bila perlu.

Data tersimpan di mana?

Tanpa login, catatan disimpan di browser perangkat ini. Jika layanan akun sudah dikonfigurasi dan kamu login, catatan akun disimpan ke Supabase. Periksa status sinkronisasi sebelum menutup halaman. Catatan lokal tidak diunggah otomatis saat login. Menghapus data browser atau memakai mode privat bisa membuat catatan hilang. Unduh cadangan secara berkala dan simpan di tempat aman.

Kamu tidak perlu memasukkan nama lengkap, nomor telepon, rekening, atau identitas orang lain. Gunakan kode seperti Pelanggan A atau Pemasok B bila perlu. File cadangan berisi catatanmu dan tidak dienkripsi. Saat dibuka dari file lokal, dukungan penyimpanan dapat berbeda antarbrowser.

Batasan versi ini

Ini alat pencatatan sederhana untuk uji coba, bukan laporan akuntansi lengkap. Belum ada kerja bersama dalam satu akun, pajak otomatis, depresiasi aset, bunga pinjaman otomatis, atau resep produksi. Retur mendukung pengembalian penuh penjualan yang sejak awal lunas; stok kembali dengan HPP asal. Fee, kemasan, dan biaya jasa yang sudah terpakai tetap menjadi biaya. Retur sebagian, retur pembelian, serta retur penjualan tempo belum didukung; jangan menghapus transaksi lama untuk menyamarkannya. Pembatalan sebelum terjadi dicatat dengan Hapus. Transfer hanya memindahkan uang antar rekening sendiri dan tidak mengubah saldo gabungan. Angka laporan mengikuti data yang dimasukkan.

Pilih jenis usaha untuk saran kategori. Semua jenis usaha tetap bisa memakai kategori sendiri, stok opsional, dan pencatatan manual. Usaha dengan proses khusus mungkin memerlukan fitur tambahan.

Catat transaksi

Tambah item stok

Stok awal tidak mengubah kas atau laba. Untuk pembelian baru, buat item dengan stok awal 0, lalu catat Pembelian stok. Mengubah stok awal akan menghitung ulang transaksi terkait.

Catat pembayaran

Cadangan data

Cadangan mencakup catatan pribadi dan bisnis, stok, serta utang/piutang. Simpan file ini untuk berjaga-jaga atau pindah perangkat.

Pulihkan dari cadangan

Data akan diperiksa dulu. Setelah kamu menyetujui, catatan di perangkat ini diganti dengan isi cadangan.

Impor pada mode akun akan disinkronkan ke akun tersebut. Dalam mode lokal, cadangan tetap di perangkat. Jangan unggah file ini ke hosting publik.

Akun & sinkronisasi

Gunakan perangkat pribadi. Catatan akun dicadangkan sementara di browser selama sesi. Keluar menghapus cache akun di perangkat ini. Unduh cadangan jika sinkronisasi gagal.
